Active tab capture

Observes responses for one selected tab after you grant optional HTTP/HTTPS host access. Remote IPs come from Chrome webRequest metadata, not DNS. Entries are stored even when Chrome omits an IP (cache/QUIC).

Captured metadata stays in Chrome session memory and is cleared when the browser or extension restarts. URLs may include path or query data — use capture only for intentional diagnostics.
